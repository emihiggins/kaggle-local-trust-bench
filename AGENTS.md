# Execution rules

Read START_HERE.md and its linked canonical documents before implementation.

- This is initially a plans-only repository. Do not describe proposed CLI commands or benchmark scores as implemented or measured.
- Preserve the frozen research protocol; version any amendment before looking at affected results.
- Reuse MLX LM and Kaggle Benchmarks. Write only the dataset, deterministic scorer, adapters, runner, and reporting needed here.
- No paid inference, subscriptions, cloud rentals, or unattended recurring LLM monitoring. Kaggle free quota only.

- Model weights, credentials, .env files, caches, raw machine identifiers and full inference logs stay out of Git.
- Do not change wired-memory limits or other macOS system settings to force a model to fit. Downsize first.
- Commit tested checkpoints. Run available secret scanning and inspect staged contents before pushes.
- Keep GitHub private. Prepare public Kaggle/DEV artifacts for Emi's review; current authorization is planning/repository creation, not publication of the entry.
- No unearned claims: evidence requirements live in product/study.md and delivery/plan.md.
